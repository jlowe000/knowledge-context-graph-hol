## APEX application scaffold

The standalone APEXlang app includes generic Oracle-generated Universal Theme and Oracle APEX Accounts login components. Project-owned pages are authored directly under `apex/application/`, with specialized conversation and graph assets maintained in `apex/explorer.css` and `apex/explorer.js`. The obsolete HTML region snapshot has been removed; it is not an authoring input. The SQL application export is generated by Oracle APEX/SQLcl from the authored application. No existing collection application's pages, search code, private data or credentials are required or included. Exported application identifiers are installation metadata and are remapped to the target workspace and schema during deployment. Oracle APEX itself is supplied by the target service and is not redistributed by this project.
