## APEX application scaffold

The standalone APEXlang app includes generic Oracle-generated Universal Theme and Oracle APEX Accounts login components, with a project-owned explorer page assembled from `apex/region.html`, `explorer.css` and `explorer.js`. The SQL application export is generated by Oracle APEX/SQLcl from that source. No existing collection application's pages, search code, private data, credentials or environment configuration are required or included. Oracle APEX itself is supplied by the target service and is not redistributed by this project.
