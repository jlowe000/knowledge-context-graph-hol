# APEX-led test coverage

This is a test audit of the dev candidate, recorded 27 November 2026. It separates offline regressions, observed native/browser results and remaining coverage. It does not publish the candidate. The authoritative chronological evidence remains [the candidate validation record](../db/verification/apex-led-candidate-validation.json); historical failures and superseded artifacts are retained.

## Current scope

Candidate-r13 has 121 canonical migrations. **Both prepared-environment core paths passed with stated coverage limits:** clean import/setup and a real learner question through new-sign-in persistence; populated published-v2 same-application upgrade, exact preservation, readiness and historical answer/evidence reopening. The candidate remains unpublished on dev. New provisioning, broader interruption modes and platform audit coverage are recorded separately below.

The offline audit ran 125 tests once across ten relevant suites, with zero failures, errors or skips. These exercise source-derived credential validation/privacy boundaries and cleanup fault branches, behavioral JavaScript input/evidence flows, APEX authoring/package structure, compressed Supporting Objects transport, immutable migration generation and replacement contract checks. They do not compile Oracle PL/SQL, prove native locking or establish browser authentication/debug behavior.
